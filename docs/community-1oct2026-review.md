## Evidence correction

The audit inputs stopped at old package catalogs and omitted active Stable 006
and Dev 023. Specter's package-only target was consequently reported absent,
even though Dev 023 contains `/ext/apps/NFC/specter.fap`, 63848 bytes, MD5
`3c977771bde9b0c6713610e6820e82d1`, SHA256
`f7a8c987acc213ee338d964b4e105a63c283c68354c32161b581152103be2b67`.

Both active catalogs were downloaded and verified by manifest identity, exact
ZIP membership, byte count, MD5 and SHA256: Stable 006 has 113 payloads, Dev 023
has 119. Their numeric GitHub release/asset IDs and catalog provenance are now
explicit audit targets. The Dev implementation and ownership pin refer to the
published Dev 009-017; the previously reviewed stable implementation pin is
preserved. A CI test checks every active channel in `current-releases.json`
against the audit target contract so activation cannot silently omit a package
catalog again. No schedule, watcher expansion or firmware API change is involved.

This corrects target-byte evidence only. Specter 3.3 NFC behavior, settings,
logs, navigation and BLE coexistence still require owner device acceptance.
